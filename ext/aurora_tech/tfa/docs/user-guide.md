# User guide — Aurora Tech TFA

This guide covers everyday use of two factor authentication (TFA) on a board running the Aurora Tech TFA extension.

## What it does

Once enabled on your account, signing in takes two steps: your password, then a six-digit code generated by an authenticator application on your device. Codes change every 30 seconds and never travel to any third-party service — verification happens entirely on the board.

Compatible applications include Aegis, Google Authenticator, Authy, 1Password, Bitwarden, and any other standard TOTP (RFC 6238) client.

## Enabling two factor authentication

1. Open the **User Control Panel → Profile → Two Factor Authentication**.
2. Click **Enable two factor authentication**.
3. Scan the QR code with your authenticator application. If you cannot scan, enter the displayed secret key manually.
4. Type the six-digit code your application shows and confirm. The code must be valid: activation is impossible without a working enrolment, so you cannot lock yourself out by accident.
5. **Save your backup codes.** Ten single-use codes are displayed exactly once. Download them as a text file or copy them somewhere safe (a password manager is a good place).

## Signing in

After submitting your password you will be asked for the current six-digit code from your authenticator application. Enter it and you are in. Your session then behaves like any normal phpBB session — the code is only asked at sign-in.

## If you lose your phone

On the verification page, choose **“I lost my phone — use a backup code”** and enter one of your saved backup codes. Each backup code works once. Once signed in:

- re-enrol your new device (disable, then enable again), or
- generate a fresh set of backup codes from the User Control Panel.

If you have lost both your device and your backup codes, use the board's **contact administrator** page — that page stays reachable — and ask an administrator to help you regain access.

## Managing backup codes

The overview screen shows how many backup codes you have left. To generate a new set, enter the current code from your authenticator application and click **Generate new codes**. The previous set stops working immediately.

## Disabling two factor authentication

Enter your account password on the overview screen and confirm. Your enrolment and all backup codes are removed. Note that if the board policy makes TFA mandatory for one of your groups, you will be walked back to the enrolment screen until you re-enable it.
